# Отчётность серии поисков

На время серии не менять код, настройки и рецепты вручную. Автоматическое обучение
рецептов сохраняется: повторный товар проверяет именно их переиспользование.

## Что сравнивать

Для каждого запроса: исходный текст, выбранная модель/комплектация, источники,
выбранный магазин, качество фото, длительность, оценка расходов и причина остановки.
Наличие рецепта на домене не доказывает, что конкретный прогон применил его:
нужны события исполнения и версия рецепта, а не только хороший итог.

## Где смотреть

| Данные | Место |
|---|---|
| Запрос, кандидатная карточка, список адресов и число Web Search | `product_source_attempts`: `research_summary`; исходный ответ и usage — `ai_runs` |
| Отсев домена, дубля, документа, исключённой страницы | `product_source_attempts`: `filter_candidate`, решение в `decision` |
| Очередь и причины приоритета | `queue_summary`, `rank_candidate`; позиция, recipe_priority, preflight_checked, reuse_only |
| Действия браузера, обучение, загрузка, Vision | существующие события в `product_source_attempts` и версии рецептов |
| Начало и итог каждого цикла фото | `cycle_started`, `cycle_finished`, связанные через `cycle_start_attempt_id` |
| Состояние карточки и незавершённый этап | `product_drafts`: gallery_status, gallery_search_stop_reason, поля согласования |
| Дочитанные страницы | `product_source_page_evidence` |
| Публикация и кнопки | существующие записи операций и обновления Telegram |

В таблице «Попытки источников» фильтр «ID запроса Telegram» объединяет записи
одного запуска даже до создания черновика. Продолжение с новым запросом имеет
свой ID; историю одного товара объединяет ID черновика. В Telegram сводка
исследования показывает ID запроса, итог карточки — ID черновика.

## Границы отчёта

- Список исследования ещё не гарантирует доступность или пригодность галереи.
- Число шагов очереди может превышать число карточек из-за проб готовых рецептов.
- `saved_file_count` — файлы на диске, не доказательство завершённого Vision.
- `estimated_search_cost_usd` — общая оценка поиска на момент записи, НЕ стоимость
  отдельного цикла и не окончательный счёт провайдера; `null` означает неизвестно.
- `cycle_finished` не означает конец всей автоматической цепочки: сверяйте статус
  и причину остановки. Резервный поиск может продолжиться тем же бюджетом.
- При смерти процесса, выключении компьютера или недоступной БД итог может отсутствовать.
  Незакрытый `cycle_started` не считать успехом; смотреть очередь и журнал приложения.
- Telegram содержит компактный прогресс, не полный DOM/текст ошибок/все URL кадров.
  Для разбора использовать таблицы. Эта доработка не обещает покрытие всех возможных
  аварий и не добавляет платных диагностических вызовов.
