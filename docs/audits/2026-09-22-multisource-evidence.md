# Несколько текстовых источников с первого поиска

## Изменение

Первый исследователь раньше возвращал одну выбранную характеристику с одной цитатой; отдельные наблюдения разных источников сохранял только инструмент дополнительного текстового поиска. Теперь первый ответ также содержит `specification_evidence`: дополнительные подтверждающие и противоречивые наблюдения. Один ключ может иметь несколько значений и источников; это не строки итоговых характеристик и не очередь фотогалерей.

Общий `ProductTextEvidenceContract` используется первичным исследованием и дополнительным текстовым поиском. Он сохраняет URL, цитату с оговорками, роль источника, область применимости и объяснение. Роль производителя нельзя вывести только из имени домена/расширения PDF; неизвестные метаданные старых наблюдений не дописываются выдуманными значениями.

Предпочтение точной применимой официальной спецификации отражено в описании контракта. Официальная страница семейства не становится автоматически доказательством установленной конфигурации. Порядок фотоисточников не меняется; противоречие и выбор остаются задачей агента, а не серверного голосования или жёсткой сортировки по типу сайта. Общее правило стратегии про равный старт источников уточнено именно для поиска фотогалереи; уже существующая тактика текстовых доказательств сохранена.

`ResearchProduct` сохраняет наблюдения и из первого ответа, и после коррекции конфигурации. Глобально заблокированные домены исключаются как в дополнительном текстовом поиске. Наблюдения попадают в существующие `saved_text_evidence` и `differing_cited_observations` финального агента. PDF вне списка магазинов не теряется из-за сортировки/дедупликации фотоисточников. Новая миграция не нужна: используется существующая колонка.

## Проверено

- Одинаковый контракт наблюдений у первого и дополнительного исследователей.
- Два разных значения одного поля проходят нормализацию/валидацию без схлопывания.
- Старые записи совместимы; им не назначается официальный статус по URL.
- Четыре интеграционных сценария: первый/исправленный ответ × точная официальная спецификация/официальный максимум семейства. Настоящие сохранение, передача агенту, разбор конфликтов и сборка; подменены ответы ИИ и этап фотогалереи.
- Блокированный текстовый источник не сохраняется; официальный PDF вне очереди фотогалерей сохраняется; выбор источника текста не меняет очередь фото.
- Целевой прогон: **39 тестов, 197 проверок**. Полный PHP-прогон после форматирования: **898 тестов, 3303 проверки, 0 падений**. Pint по затронутым PHP-файлам и `git diff --check` прошли. JavaScript не менялся; Node в этой правке повторно не запускался.

## Ограничения

Тест с подменённым ответом доказывает сохранение и передачу доказательств, не безошибочность живой модели. Метаданные применимости и цитаты исследователя сами требуют разумной оценки агентом. Всеобщей гарантии 100% точности нет; ошибаться могут и производитель, и магазин. Неопределённость не должна маскироваться уверенностью.

Новых обязательных платных вызовов, квоты числа источников, изменений бюджета/рецептов/воркера нет. Структурированные наблюдения увеличивают размер ответа/контекста при их наличии; нулевая стоимость этого расширения не обещается. Уже известную одиночную цитату не требуется дублировать, отсутствующие дополнительные наблюдения возвращаются пустым массивом. Платные поиски не запускались, рабочая БД и клиентский архив не изменялись.
