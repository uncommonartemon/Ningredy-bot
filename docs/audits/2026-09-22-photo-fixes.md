# Исправления после клиентского аудита — 22.09.2026

Основание: [аудит архива](2026-09-22-client-photo-audit.md). Это отчёт о конкретных исправлениях, не объявление готовности всего модуля.

## Что изменено

1. **Переход на галерею.** Другой заголовок/слоган не доказывает другой товар. Совпадение названий тоже не доказывает идентичность. При недостаточных данных разрешённое исследование продолжается с `identity_unconfirmed`; реальное противоречие сопоставимых SKU/MPN/GTIN по-прежнему останавливает сбор с чужой страницы. Изменение названия учитывается и при сохранении прежнего URL.
2. **Решение тренера остановиться.** `abandon_page` на товарной/неопределённой странице завершает текущую попытку без платного цикла ошибок валидации. Это не постоянный запрет страницы и не повод отключать рецепт домена. Уже найденный частичный набор сохраняется. Для постоянного правила непригодности остаются отдельные требования доказательств.
3. **Региональная комплектация в резервном поиске.** До дорогого обучения проверяются уже полученные сведения страницы. Когда буквального подтверждения нет, источник получает проверку агентом, как в основной очереди. Только вердикт `conflicting` отклоняет его; `uncertain`/`unavailable` не превращаются в доказательство чужого товара. Это условный дополнительный вызов ИИ, а не бесплатная проверка.
4. **Повторные вопросы идентичности.** Завершённый ответ переиспользуется только внутри того же поиска, с тем же провайдером/моделью и идентичным входным текстом. Новые данные или новый поиск требуют новой проверки. Технические отказы не кэшируются как вердикты. Перед новым вызовом проверяется общий бюджет.
5. **Ложное отключение магазина.** Одно лишь AI-решение `blocked` не записывается как CAPTCHA всего домена. Наблюдения настоящей браузерной защиты обрабатываются прежним отдельным путём. Выбор страны автоматически проходить эта правка не учит.
6. **Контекст обучения.** При наличии актуального наблюдения исходный большой DOM больше не дублируется в каждом раунде. Первый снимок сохранён на сервере и доступен агенту через инструмент чтения; запрос полного наблюдения не запрещён.
7. **Vision.** Одинаковые места в рейтинге допустимы; идентификаторы кадров остаются уникальными. Противоречивые положительные оценки с низким баллом/неопределённым типом возвращаются модели на одну ограниченную перепроверку с конкретной ошибкой. Сервер не умножает баллы и не подтверждает кадры сам. После неудачной перепроверки сохраняются непротиворечивые оценки остальных кадров; если таких нет — ошибка, а не ложное «подходящих фотографий нет». Ответ и usage фиксируются до валидации.
8. **Сборка карточки.** Новая формулировка того же `not_ready` без новых данных не оправдывает третий одинаковый вызов. Длинное служебное `summary` обрезается без потери всей оплаченной сборки; поля фактов не обрезаются этой правкой.
9. **Очередь источников.** Метка `web` больше сама по себе не выкидывает товарную страницу из основной очереди. Остальные фильтры URL, банов и идентичности сохранены. Обзоры/каталоги не объявлены автоматически пригодными.

## Проверки и границы доказательства

- PHP: новые регрессии на остановку тренера, здоровье домена, предобучающую проверку идентичности, кэш одинаковых вопросов, повторный `not_ready`, длинный ответ и Vision. ИИ подменён фиксированными ответами; это не измерение качества живой модели.
- Реальный Chromium и настоящая точка входа `extract-product-gallery.mjs`: локальный тестовый транспорт подаёт HTML/изображения без внешнего сайта. Проверены смена заголовка, сохранение URL при изменении страницы, совпадающий/конфликтующий SKU, обход циклической и конечной галереи, динамические миниатюры, zoom, iframe/вложенный iframe, статические оригиналы и один сбой загрузки среди рабочих кадров.
- Регрессия переноса: обучение на товаре A → использование на B с другим количеством фото, без второго вызова тренера. Браузер в этом PHP-тесте подменён; реальные циклы браузера проверены отдельно выше.
- Полный `php artisan test --compact`: **873 теста, 3211 проверок, 0 падений**.
- Полный `npm test`: **125 тестов, 0 падений, 0 пропусков**. Первый полный Node-прогон выявил Windows `EBUSY` при удалении временной папки после успешного браузерного сценария; добавлен ограниченный повтор очистки только проверенного тестового каталога. Повторный полный прогон прошёл.
- Pint по PHP-файлам этой работы и `git diff --check` проходят.

## Что не объявлено исправленным

- Автоматическая гарантия переносимости каждого старого рецепта с товароспецифичными селекторами. Существующие данные рецептов не переписаны.
- Ранее отложенная стратегия «чистый слайдер первым, маркетинговую галерею в резерв». Требует отдельного согласованного изменения стратегии, а не скрытого включения в этот фикс.
- Все спорные характеристики опубликованных клиентских карточек; новая логика не исправляет их задним числом.
- Потеря контекста короткого пользовательского уточнения без названия товара — отдельный маршрут Telegram, не закрыт этими исправлениями фото.
- Независимая визуальная оценка клиентских изображений: их байтов в архиве нет.
- Повторный платный прогон клиентских запросов на живых магазинах не выполнялся. Процент экономии и процент успешных поисков не измерены.

Рабочую БД, фотографии, настройки моделей, старые рецепты и запущенные воркеры в этой работе не меняли. Архив клиента не добавлялся в Git. Остальные уже имевшиеся изменения рабочего дерева сохранены.
